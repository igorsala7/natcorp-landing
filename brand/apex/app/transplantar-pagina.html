Transplantar página APEX

Leva a exportação de uma página para outro app, outro workspace ou outra base — sem instalar a aplicação inteira por cima. O arquivo gerado importa pelo App Builder do destino como se a página tivesse sido exportada lá.

Tudo roda neste computador: nenhum arquivo sai daqui
1

As páginas que vão mudar de lugar

A exportação da página (App Builder › Exportar › Página/Componente) do app de origem. Pode soltar várias de uma vez: todas vão para o mesmo destino.

2

O app de destino

A exportação completa do app de destino (confere tudo). Se não houver, qualquer página exportada de lá já serve para cópias do mesmo app — o que ela não usar sai como "não conferido".

3

O app de origem só se os apps não forem cópias um do outro

Para apps diferentes, cada modelo, breadcrumb, grupo de páginas e interface é traduzido pelo nome — e para isso é preciso a exportação completa da origem. Entre cópias do mesmo app (200, 202, 207…) pode deixar em branco.
